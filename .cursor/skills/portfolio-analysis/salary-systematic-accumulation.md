# Salary / Systematic Accumulation — Building Quantity Over Time

Use with `portfolio-analysis/SKILL.md`, `pccl-analysis/premium-add-sizing.md`,
and `stock-analysis/comparative-scorecard.md`.

---

## Purpose

Many investors deploy capital from **monthly salary**, not lump sums.
Wealth compounds from:

```
Wealth ≈ Quantity held × (Future price − Average cost)
```

**Quantity builds slowly** at acceptable prices — not from one bulk buy
or emotional **upward averaging** because the stock is green today.

This template separates:

| Pattern | Definition | Framework |
|---------|------------|-----------|
| **Systematic accumulation** | Fixed ₹ or share tranche on schedule when thesis + price rules pass | **Allowed** — primary path for salary investors |
| **Fair-value scale-in above PCCL** | Adds at CMP above PCCL when MoS vs IV ≥ 0%, with premium size caps — user term “upward averaging” | **Allowed** — primary wealth path; PCCL protects size, not entry |
| **Premium-tier scale-in** | One-off add at fair value on existing winner | Size-capped lump (see premium-add-sizing) |
| **Momentum / FOMO averaging** | Add mainly because price rose / stock “looks strong” — no caps or IV check | **Avoid** |

See `pccl-analysis/pccl-as-protection-not-target.md`.

## When systematic accumulation is allowed

All must pass (same bar as premium add, minus lump-sum urgency):

1. **Business quality** Strong or Moderate+ with durable evidence
2. **No unresolved core problem**
3. **Thesis intact** — latest 2–4 quarters support (not one headline)
4. **Management & governance** Adequate or better for sector (banks: run fraud/governance screen)
5. **Price rule** — see tranche pace table below
6. **Concentration** — projected weight after 12-month plan stays within portfolio cap (~15–20% single name)
7. **Opportunity cost** — name ranks acceptably vs other deploy candidates for *this month's* surplus

If management is **Weak** with open regulatory overhang → **pause DCA** (HDFC Aug 2026 pattern).

## Tranche pace vs valuation (monthly salary deploy)

Use **Premium to PCCL** and **MoS vs Conservative IV** to set **pace**, not binary buy/skip.

| Premium to PCCL | MoS vs IV | Monthly tranche (vs existing qty) | Notes |
|----------------:|----------:|----------------------------------:|-------|
| **< 0%** (below PCCL) | Any if core-problem passes | **+3–5% of qty** or max affordable ₹ | Best accumulation zone |
| **0–15%** | ≥ 0% | **+2–4% of qty** | Steady DCA |
| **15–25%** | ≥ 0% | **+1–2% of qty** | Slow DCA only |
| **25–40%** | ≥ 0% | **+0.5–1% of qty** or **pause** | Token only; prefer dips |
| **> 40%** | Any | **Minimal token** (tier 1) | Never zero on Strong quality — see `continuous-sip-valuation-tiers.md` |
| Any | **< 0%** (above normal IV) | **Token only** (tier 1–2) | Slowest pace + blended cap — not full pause |

**₹ tranche alternative:** deploy **10–25% of monthly investable surplus** to the name when pace row allows — whichever is **smaller** after concentration check.

## Governance era rule (banks / turnaround names)

When user cites **“bad past 10 years”**:

1. Split history into **eras** (e.g. pre-2018 vs post-2018 CEO)
2. Rate **current management** separately from legacy scandal (stock-agent §5)
3. **Legacy scandal resolved** (conviction, exit, RBI clean leadership) → does not block DCA if current era is Adequate+
4. **Open regulatory / CEO denial vs regulator finding** → pause adds until catalyst clears

Past bad governance **does not** mean forever avoid if current era is verified different — but **does** cap conviction and requires live search each review.

---

## Anti-patterns

- “Stock is performing → buy more now” without price rule
- Double monthly tranche because of FOMO after rally
- Ignore opportunity cost — feeding one name while better PCCL gap elsewhere
- Treat DCA as permission to ignore **Weak** management (banks)
- Bulk buy with 6 months salary in one week at premium to PCCL
