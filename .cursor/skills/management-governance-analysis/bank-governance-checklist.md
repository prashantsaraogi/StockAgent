## Rating guide (banks)

| Mgmt rating | Criteria | Fresh capital |
|-------------|----------|---------------|
| **Strong** | Clean regulatory record; stable board; CEO succession clear; no open probes | Full size if valuation OK |
| **Adequate** | Minor historical penalties; resolved issues; transparent board | Normal sizing |
| **Weak** | Open probe + chairman/CEO friction + pending RBI; pattern of conduct issues | **No add** until clarity |
| **High risk** | Material RBI strictures, fraud finding, key-person disqualification | **Trim / avoid** |

**Rule:** For D-SIB banks, **Weak management caps conviction** even at 52-week low.

| Item | Label |

| RBI deposit **gift / account** penalties (2024) | FACT |

### Management assessment questions

1. Is there an **open RBI/SEBI** matter with unknown outcome?
2. Did **independent chairman** leave with ethics language without detail?
3. Is **CEO succession** within 6 months with overhang?
4. Was conduct labeled **overreach** vs **mala fide** — what could RBI conclude differently?
5. Does market apply **governance discount** (P/B, P/E vs history)?

### PCCL / action overlay (governance)

| Condition | Action |
|-------------|--------|
| RBI review **pending** + CEO term ending | **No add**; lower PCCL ₹30–50 vs pure NIM model |
| RBI **mild closure** + CEO reappointed | Reassess add; governance → Adequate |
| RBI **material penalty** / stricture | **Trim** if overweight; lower PCCL sharply |
| Only internal review cleared, market still sells | **Wait** — priced-in test fails |

### Catalyst calendar (copy and update)

| Date / window | Event | If favourable | If adverse |
|---------------|-------|---------------|------------|
| Q2 FY27 results | NIM bottom? | Staged add zone | Wait |
| **RBI MSRDC outcome** | Mild rap | PCCL ↑ | No add / trim |
| **Oct 2026** | CEO reappointment | Stability | De-rate |
| Permanent chairman appointed | Board stability | Small + | — |

## Other banks — quick flags

| Bank type | Extra checks |
|-----------|--------------|
| **Private bank (D-SIB)** | Chairman stability, RBI relationship, deposit conduct |
| **PSU bank** | Government interference, recap history, NPA cycles |
| **Small finance / NBFC** | Promoter pledge, ALM, RBI scale-based norms |
| **Post-merger bank** | Integration governance, board composition, culture clash |
