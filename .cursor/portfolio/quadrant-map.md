## How quadrants work

```
                    HIGH GAIN (return ≥ 50% vs your avg cost)
                              │
     Q1                       │              Q2
     Underweight winners      │              Core winners
     (low weight + high gain) │              (high weight + high gain)
     → Priority ADD           │              → HOLD; size-cap new adds
                              │
 LOW WEIGHT (<2.5%) ──────────┼────────── HIGH WEIGHT (≥ 4%)
                              │
     Q4                       │              Q3
     Small laggards           │              Heavy anchors
     (low weight + low gain)  │              (high weight + low gain)
     → HOLD; no new capital   │              → HOLD; pause adds on weak names
                              │
                    LOW GAIN (return < 15%)
```

| Axis | Threshold |
|------|-----------|
| **Low weight** | < 2.5% of portfolio value |
| **High weight** | ≥ 4.0% of portfolio value |
| **High gain** | Return ≥ +50% vs avg cost |
| **Low gain** | Return < +15% vs avg cost |
| **MID** | Between thresholds — see master table |

**Gain %** = (CMP − avg cost) / avg cost × 100  
**Weight %** = position value / total portfolio value × 100

## How to update this file

### When you trade

Tell the agent:

```
Update portfolio: bought [TICKER] [qty] @ [price]
Refresh quadrant map from holdings.md with latest CMP.
```

The agent should:

1. Update [holdings.md](holdings.md) (qty, avg cost, change log)
2. Fetch **live CMP** on that date
3. Recalculate return %, weight %, quadrant
4. Update this file’s **Last refreshed** date and change log below

### When to full refresh (no trade)

- After quarterly results season (optional)
- When Nifty moves **>8%** from last CMP date
- Once every **3–6 months** if no trades

Say:

```
Refresh portfolio quadrant map — read holdings.md, live CMP today.
```

### Manual edit

If you edit [holdings.md](holdings.md) yourself, ask for a quadrant refresh — do not hand-edit quadrant math unless you recalculate all weights.
